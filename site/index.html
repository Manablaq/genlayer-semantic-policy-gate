GenLayer Intelligent Contract

Reusable policy decisions for contracts, agents, DAOs, and marketplaces.

SemanticPolicyGate registers natural-language policies and resolves submitted content into structured decisions: allowed, denied, needs_review, or error. 

policy + subject + content + context -> allowed / denied / needs_review

Why It Matters

Policy Registry

Versioned policy records keep decisions tied to the exact rules used.

Resolver Profiles

Use deterministic checks for structured evidence and semantic consensus for ambiguous content.

Verifier API

Downstream contracts can call is_allowed, is_denied, needs_review, and is_fresh.

Architecture

Core API

register_policy(name, policy_text) -> u256
submit_decision(policy_id, subject, content_uri, content_text, context, ttl_seconds) -> u256
resolve_required_fields_decision(decision_id) -> None
resolve_semantic_decision(decision_id) -> None
get_decision(decision_id) -> Decision
is_allowed(decision_id, min_confidence) -> bool
is_denied(decision_id, min_confidence) -> bool
needs_review(decision_id) -> bool
